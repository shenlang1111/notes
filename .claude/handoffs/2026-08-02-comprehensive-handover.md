## 8. 已知的坑（Gotchas）

- **部署超时**：Pages 构建有 360s 超时限制，大文件多时可能超时。文件已上传成功，构建可能仍在 GitHub 侧排队
- **同一文件必须串行编辑**：并行会互相覆盖，导致内容丢失。多次踩坑
- **多 AI 并发部署会 409**：其他 AI 也在改/部署时，deploy 会报 409 冲突并中止——先拉线上版本对比（确认对方无独有内容后）再强制覆盖重部署
- **部署上传必须串行**：GitHub 并发写返回 409
- **验证线上用 Node fetch**：PowerShell 的 Invoke-WebRequest 抓 GitHub Pages 会误报 404
- **手机/微信缓存**：改版后加版本参数 `?v=` 强制刷新，或让用户 Ctrl+Shift+R
- **Token 安全**：在 `.env`，不硬编码、不在对话里传
- **源文件无对应 MD**：两个源文件（root 级）没有对应的 MD 版本，因为它们是转换脚本的原始产物，不是知识库正式页面
