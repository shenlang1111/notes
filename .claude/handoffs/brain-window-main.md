## 铁律（必须遵守）

1. **双格式成对**：改 HTML 必须同步改 MD（反之亦然）
2. **部署**：所有修改用 `node tools/deploy.js --files <清单>` 上线
3. **--expect 验证**：部署必须带 `--expect "文件:关键词"` 验证本次修改
4. **DoD 自检**：宣布"完成"前展示自检清单（CHANGELOG/双格式/部署/--expect）
5. **响应四问**：理解了吗 / 讨论还是执行 / 读了吗 / 谁拍板
6. **知识问题先翻库**：先翻库、再开口；带出处、不编造；翻不到说"没找到"
7. **说人话**：中文、通俗、表格，不堆缩写
8. **用户拍板**：你只提供分析和材料，决定权在用户
9. **新机制"谁建谁记"**：广播到 mechanism-updates
10. **并行分派**：≥3 个独立文件的任务默认拆子代理并行（同一文件串行）
11. **验收标准**：验收执行窗口成果时，按蓝图对应层的验收标准逐条对照，不达标打回
