APG（烷基糖苷）——绿色表面活性剂

APG（Alkyl Polyglycoside，烷基糖苷）是由可再生资源（葡萄糖+脂肪醇）合成的非离子表面活性剂，兼具绿色环保与卓越性能，被誉为"21世纪的绿色表活"。

非离子 APG 烷基糖苷 绿色表活

什么是APG？

APG（Alkyl Polyglycoside，烷基糖苷）是由可再生天然资源——葡萄糖（来自玉米淀粉）和脂肪醇（来自椰子油/棕榈油）——通过糖苷键连接而成的非离子表面活性剂。其分子结构同时含有亲水的糖基和疏水的烷基链，兼具优异的表面活性和极佳的环保特性。

APG是全球公认的绿色表面活性剂，已通过ECOCERT/COSMOS等国际天然认证，在日化、工业清洗、农业助剂等领域得到广泛应用。

1. APG 概述

APG是非离子表面活性剂的重要品种，属于聚糖苷类表面活性剂。其最大特点在于100%来自天然可再生资源，同时具备优异的表面活性，是绿色化学在日化领域最成功的应用之一。

2. 合成工艺

APG的工业化生产主要有两种工艺路线：

方法一：直接苷化法（一步法）

反应式：葡萄糖 + 长链脂肪醇(C8-C18) →(酸性催化剂，100-120°C) APG + H₂O

特点：

  • 工艺简单，一步反应
  • 葡萄糖在脂肪醇中溶解性差，反应速率慢
  • 产物颜色深（需脱色处理）
  • 副反应多（葡萄糖焦化、聚合）

方法二：转糖苷化法（两步法，主流工业工艺）

第一步：葡萄糖 + 丁醇 →(80-120°C，酸性催化剂) 丁基糖苷

第二步：丁基糖苷 + 长链脂肪醇 →(高真空，脱醇) APG + 丁醇↑（回收循环）

特点：

  • 反应条件温和，产品质量好
  • 产物颜色浅，无需深度脱色
  • 通过控制蒸出丁醇的量可精确控制聚合度（DP）
  • 丁醇可回收循环使用，经济性好
  • 目前全球主流APG生产商均采用此工艺

工艺参数要点：

  • 催化剂：对甲苯磺酸（p-TSA）或固体酸催化剂
  • 反应温度：100-120°C（直接法）/ 80-120°C（转糖苷化法）
  • 醇糖比：影响DP和产物分布
  • 后处理：中和催化剂 → 脱色（H₂O₂）→ 蒸馏脱醇 → 调配

3. 结构与分类

APG的分子结构通式：RO-(G)ₙ，其中R为烷基链（C8-C18），G为葡萄糖单元，n为平均聚合度（DP，通常1.2-1.8）。

5. 性能特点

APG 核心优势

  1. 绿色可再生：100%来源于天然可再生资源，完全生物降解，ECOCERT/COSMOS认证
  2. 温和无刺激：对皮肤和眼睛刺激性极低，优于氨基酸表活
  3. 优异的表面活性：低CMC、低表面张力，乳化/去污/分散性能优异
  4. 极佳的配伍性：与各类表活均可复配，协同效应显著
  5. 耐硬水/耐电解质：不受Ca²⁺/Mg²⁺影响
  6. 无浊点限制：可在高温下使用（>100°C）
  7. 低气味、浅色：不影响配方香精体系

APG 局限性

  1. 成本较高：比AEO、LAS等传统表活贵2-3倍
  2. 增稠需辅助：需配合电解质或聚合物增稠剂
  3. 低温流动性：高浓度（>50%）低温粘稠度高，泵送需加热
  4. 水分敏感：长期高水分条件下可能发生水解

9. 环境与安全

APG 的环境友好特性

  • 生物降解性：28天生物降解率>90%（OECD 301B）
  • 水生毒性：LC50（鱼类）>100 mg/L，低毒
  • 皮肤刺激性：无或极轻微（OECD 404）
  • 眼刺激性：轻微至无刺激性（OECD 405），适合无泪配方
  • 生态认证：ECOCERT/COSMOS天然化妆品认证，Nordic Swan生态标签
  • 碳足迹：原料来自可再生资源，远低于石油基表活
