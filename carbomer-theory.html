第 1 层 · 定位：卡波姆站在哪

1.1 卡波姆在配方里干什么

日化/化妆品配方的骨架是"基质 + 表活 + 增稠剂 + 防腐 + 香精"。增稠剂是"承重墙"——决定产品的粘度、质地、肤感和悬浮能力。卡波姆是增稠剂里最主流的一类（合成高分子增稠），也是天赐表活之外的第二条产品线。

1.2 增稠的四种机制（先看地图）

为什么有这么多增稠剂？因为增稠的"力"有四条路。这四张类比帮你秒懂：

机制靠什么力类比代表成分天赐关联
电解质增稠盐屏蔽胶束电荷排斥，促胶束长大给互相排斥的磁铁加铁壳NaCl 0.5-2%AES 体系常用；CAB 协同增稠是替代方案
胶束增稠表活超 CMC 形成蠕虫状胶束，物理缠结面条缠成一团甜菜碱 + 阴离子表活TC-CAB 35 核心功能
高分子增稠高分子链伸展缠结形成物理网络粥糊化黄原胶、纤维素、瓜尔胶与表活体系复配
卡波姆增稠交联聚丙烯酸中和后电荷排斥，网络膨胀海绵吸水膨胀Carbomer 0.1-0.3%TC-CARBOMER 系列
为什么这对你值钱：胶束增稠（CAB + 阴离子表活）是你卖表活的核心；卡波姆增稠是你另一条线。客户配方里"增稠"这件事，你两条腿都能站——这是卖组合方案的地基。

1.3 增稠剂家族横向对比（客户为什么用卡波姆？）

增稠剂类别透明度耐盐触变性典型用量一句话定位
卡波姆合成（交联聚丙烯酸）极高差（疏水改性款耐盐）强（剪切变稀）0.1-1.5%透明凝胶/膏霜首选

选型逻辑一句话：要透明 → 卡波姆；要耐盐/便宜 → 黄原胶；要温和保水 → 纤维素；要成本最低 → 瓜尔胶。卡波姆的生态位 = 高透明 + 强悬浮 + 用量省，代价是怕盐、必须中和。客户"为什么用卡波姆不用黄原胶"的答案：他要透明凝胶和膏霜质地，黄原胶做不出来。

第 2 层 · 原理：本质与 8 个为什么

2.1 化学本质：一条绳上挂满钩子，再织成网

卡波姆（Carbomer，INCI 名 CARBOMER）= 交联聚丙烯酸。每个丙烯酸单元挂一个羧基（-COOH），交联剂（烯丙基蔗糖/季戊四醇烯丙醚）把长链"焊"成三维网络。关键推论：交联聚合物只能溶胀、不能溶解（《高分子物理》：三维网状高分子不溶于水，只能吸水膨胀）——这就是卡波姆"吸水变胶、不变成溶液"的本质。

2.2 三种增稠力（完整机制体系）

力怎么来的何时主导对应天赐牌号
① 电荷排斥（主线）中和后 -COOH→-COO⁻，同性相斥撑开网络绝大多数配方（必须调 pH）全部常规系列（276/340/380/396…）
② 氢键（辅助）羧基（给体）与非离子表活/多元醇的羟基（受体）成氢键不想调 pH 的体系；与 APG/AEO 复配时叠加与表活复配时全系列通用
③ 疏水缔合（增强）链上引入 C10-30 长烷基"油锚"，疏水尾巴互相抱团成物理交联点含盐/含离子表活体系（盐只屏蔽电荷，屏蔽不掉油锚）FD20/21/2010/2020 疏水改性四兄弟

看懂这张表，卡波姆的"怕盐"和"耐盐"就不再是玄学——怕盐是因为只有①电荷力；耐盐是因为多了③疏水缔合。两条路增稠，一条被盐打断还有另一条。

2.4 八个为什么（现象 → 分子机制 → 对应牌号 → 客户语言）

为什么 1：必须调 pH？——给钩子"通电"

步骤分子层面类比
① 分散羧基未电离（-COOH），链卷曲成团干海绵
② 加碱中和-COOH + OH⁻ → -COO⁻ + H₂O给钩子通电
③ 电荷排斥-COO⁻ 同性相斥撑开分子链弹簧床撑开
④ 网络膨胀三维网络吸水膨胀锁水 → 变稠海绵吸饱水

深度点（药典实证）：羧基 pKa ≈ 4.5-5。pH 低于 4 几乎不电离 → 不增稠；pH 5-7 电离度快速上升 → 粘度猛涨；pH 6～11 黏度最大，pH<3 或 >12 或强电解质 → 黏度明显下降（USP-NF）。中和换算：1g 卡波姆 ≈ 0.4g NaOH。

→ 对应天赐牌号：全系列通用（这是"网怎么撑开"，所有卡波姆的命根子）

为什么 2：氢键也能增稠？——第二条路，不用调 pH

羧基（-COOH，氢键给体）和非离子表活/多元醇上的羟基（-OH，受体）形成氢键，同样解开卷曲链、织成网络。特点：不用调 pH，但增稠慢、效果温和。

  • 与你的关联：APG、AEO 这类非离子表活和卡波姆搭配时，中和增稠 + 氢键增稠双叠加——这就是"表活 + 卡波姆双保险"的分子基础
→ 对应天赐牌号：非离子表活体系（APG/AEO）复配时全系列受益

为什么 3：怕盐？——网被"沙袋"压塌（物理必然）

盐电离出的 Na⁺ 跑去"中和"卡波姆链上的 -COO⁻，把电荷排斥屏蔽掉 → 网失去撑开的力 → 塌缩 → 粘度断崖。卡波姆增稠动力 100% 来自电荷排斥（中和增稠），电荷没了网就散。"怕盐"不是缺陷，是这种增稠机理的物理必然。

  • 敏感度：盐超 0.1-0.5% 明显影响（视型号）；离子型表活（AES、LAS、氨基酸表活）自带离子，同理削弱——"含表活体系"和"含盐体系"本质是同一类问题
  • 客户语言："盐离子像给渔网压上沙袋，网眼被压塌，水兜不住了"
→ 对应天赐牌号：怕盐=常规 11 款；耐盐=FD20/21/2010/2020（疏水改性四兄弟）

为什么 4：疏水改性为什么耐盐？——多加了一把"油锚"

聚合时引入长链疏水共聚单体（甲基丙烯酸月桂酯/十六酯/十八酯，即 C10-30 烷基丙烯酸酯）——链上长出不亲水的长烷基尾巴。这些尾巴怕水，互相抱团成物理交联点。于是网络有两种力：①电荷排斥（同普通卡波姆）②疏水缔合（普通卡波姆没有）。盐只屏蔽电荷排斥，屏蔽不掉疏水缔合——电荷没了，油锚还在勾着，网就不塌。

对比普通卡波姆疏水改性卡波姆
撑网的力只有电荷排斥电荷排斥 + 疏水缔合
耐盐性差（盐一来就塌）强（1% NaCl 实证不塌）
与离子表活配伍差好（氨基酸体系也能用）
INCI 名CarbomerAcrylates/C10-30 Alkyl Acrylate Crosspolymer
→ 对应天赐牌号：FD20/21（短流）、FD2010/2020（长流）；INCI 名可直接在成分表辨认

为什么 5：乙醇让凝胶发白？——"泳池水"换成"酒"

乙醇浓度 ≥70-75% 时凝胶发白不透明。分子机制（原理推断 ⚠，现象 TDS 实证）：① 乙醇介电常数（约 24）远低于水（约 80）→ 极性大降 → 羧基电离度下降 → 电荷撑不开；② 乙醇对高分子是较差溶剂（去溶剂化）→ 链段收缩聚集 → 光线散射发白。

→ 对应天赐牌号：TC-CARBOMER 351（乙醇相容，70% 乙醇下透光率 ≥85%）——免洗消毒凝胶指定款

为什么 6：剪切变稀？——网"拆了还能装回去"

搅拌变稀、静止恢复（假塑性/触变性）。三个卖点都从这里来：悬浮（静止够稠，珠光粉/防晒剂不下沉）· 施工（搅拌变稀，能耗低）· 肤感（涂抹顺滑，涂后定型）。

  • 客户语言："像摇一摇的番茄酱——用力就稀，放着又稠回来"
  • 注意：过度/长时间高速剪切会"打废"——网络恢复需要时间，生产要控制搅拌强度
→ 对应天赐牌号：全系列共性；悬浮场景优先 FD10（防晒）/短流款

为什么 7：短流 vs 长流？——网眼密度的差异（选型第一道分水岭）

性格分子根源表现适合
短流交联密度高，网络致密结实"嘎嘣脆"，稠厚膏状凝胶、膏霜、牙膏
长流交联密度低，网络疏松柔韧慢悠悠拉丝、流动乳液、低粘悬浮
→ 对应天赐牌号：短流 340/380/396 等主流 · 长流 341/381/FD2010/2020

为什么 8：交联密度决定粘度？——药典实证

原来这是"原理推断 ⚠"，现在有药典数据坐实：低黏度、低硬度的卡波姆 → 交联分子量高（交联密度低）；高黏度 → 交联分子量低（交联密度高）（USP-NF 综述，941 交联分子量实测 237,600/104,400 g/mol）。卡波姆树脂分子量理论范围 7×10⁵～4×10⁶。粘度档 = 交联密度的宏观体现。

→ 对应天赐牌号：396/276 最高粘（网络最致密）· 341/381 最低粘（网络最疏松）

6.2 苯残留口径澄清（卖点不说过头）

重要：药典医药级限值苯 ≤0.0002%（0.2 ppm）；USP-NF 通用级各型号不同（910/934/940/941 ≤0.5%，934P ≤0.01%，1342 ≤0.2%）。天赐 TDS 标"340/341/396 ≤0.50%"符合 USP 通用级口径。跟客户讲"无苯"，要讲"低于医药级标准"或"符合 XXX 级限值"，别说成"绝对零苯"——被较真就翻车。

6.4 配伍禁忌与稳定性（客户技术问题素材）

  • 不相容：间二苯酚（变色）、苯酚、阳离子聚合物、强酸、高浓度电解质；痕量铁/过渡金属催化降解
  • UV 敏感：中和后水凝胶紫外线照射黏度急剧下降；TEA 作中和剂可改善 UV 稳定性；UV 吸收剂（二苯甲酮-2/4）+ EDTA 可防护
  • 热稳定性：104℃ 加热 2h 不影响增稠；260℃ 30min 完全分解
  • 防腐：干粉不长霉，无防腐水分散液易长菌；建议 0.1% 氯甲酚 / 0.18% 羟苯甲酯；苯扎氯铵/苯甲酸钠高浓度（0.1%）可致浑浊降黏
销售用法：客户问"卡波姆安不安全"——报三组数据：①实际用量 0.1-1.5% vs CIR 上限 15%；②高分子聚合物豁免透皮评估；③药典收载辅料 + LD50 数据。比一句"很安全"有说服力得多。
