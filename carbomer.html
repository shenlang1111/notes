30 秒速览 · 先记住 3 句话

第 1 句：卡波姆 = 一张能兜水的网

分子上是"聚丙烯酸 + 交联剂"搭成的三维网络。单根高分子链兜不住水，织成网才能把水锁住。类比：渔网——单根鱼线会漏，网能兜住鱼（水）。

第 2 句：这张网靠"电荷"撑开

加碱中和 → 羧基带上负电荷（-COO⁻）→ 同性相斥把卷曲的网撑开 → 吸水膨胀 → 变稠。所以不调 pH 就是废的，盐会把网压塌。

第 3 句：18 个牌号 = 4 个原理变量的组合

交联密度 → 粘度；疏水改性 → 耐盐；合成溶剂 → 苯残留；表面处理 → 分散快慢。看懂这 4 个变量，18 个牌号全是同一件事的不同组合，详见第 3 部分。

销售开场一句话："卡波姆就是让产品变稠、变透亮、能把粉末粒子悬浮住的高分子增稠剂。天赐做这个做了二十多年，18 个牌号对应不同配方场景——您配方里盐多不多、要不要透明、做不做酒精消毒液，决定了用哪个型号。"

分子原理深挖 · 8 个为什么

不要求记化学式，但每个"为什么"都讲到分子层面——因为只有懂到分子层，客户问到任何怪问题你都能接得住。

2.1 卡波姆到底是什么？——一条绳上挂满钩子

卡波姆（Carbomer，INCI 名 CARBOMER）= 交联聚丙烯酸。聚丙烯酸是很多丙烯酸分子手拉手连成的长链，每条链上每个重复单元都挂一个羧基（-COOH）——这就是后面所有故事的起点。

聚丙烯酸长链
C-C 主链
────
羧基 -COOH
每个单元挂一个"钩子"
────
交联剂架桥
链与链之间"搭桥"
  • 类比：一条绳子上每隔一段挂一个小钩子，钩子就是羧基；交联剂是绳子之间的"桥"，把散绳织成网
  • 深度点：交联剂是烯丙基醚类多官能单体（如季戊四醇三烯丙基醚），一个分子带多个可聚合双键，把两条链"焊"在一起
  • 客户语言："卡波姆像一张看不见的渔网，网眼越密、网越结实，兜水越厉害"

2.2 为什么必须调 pH？——给钩子"通电"

这是卡波姆增稠的核心，也是客户翻车最多的地方。

步骤分子层面发生了什么类比
① 分散粉末撒入水中，羧基未电离（-COOH），分子链靠氢键/范德华力卷曲成团干海绵丢进水里，还没吸水
② 加碱中和-COOH + OH⁻ → -COO⁻ + H₂O，羧基电离带上负电荷给钩子通上电
③ 电荷排斥-COO⁻ 同性相斥，把卷曲的分子链从内部撑开、伸展弹簧床被撑开
④ 网络膨胀伸展的链把三维网络撑开，吸水锁水 → 体系变稠海绵吸饱水、胀开

深度点：pH 与电离度的关系（说给技术型客户听）

羧基的 pKa ≈ 4.5~5。pH 低于 4 时几乎不电离 → 不增稠；pH 5~7 电离度快速上升 → 粘度猛涨；pH 7 以上基本饱和 → 粘度进平台。这就是"客户用卡波姆翻车 90% 是 pH 没调到位"的分子原因——不是卡波姆坏了，是电荷没给够。

常用中和剂：氢氧化钠（NaOH）、三乙醇胺（TEA）、氨甲基丙醇（AMP）。调到 pH 6~7 最稳。

客户语言："卡波姆不调 pH 就是废的——钩子没通电，网撑不开，自然不稠。客户说凝胶没粘度，第一件事就问 pH 中和了没有。"

2.3 氢键增稠：第二条路（不用调 pH）

除了电荷，还有一条增稠路：羧基（-COOH，作氢键给体）和非离子表活/多元醇上的羟基（-OH，作受体）形成氢键，同样能把卷曲的链解开、织成网络。

  • 特点：不用调 pH，但增稠慢、效果温和
  • 与你的关联：APG、AEO 这类非离子表活和卡波姆搭配时，除了中和增稠，还叠加氢键增稠——这就是"表活 + 卡波姆双保险"的分子基础
  • 客户语言："某些配方不想调 pH，靠非离子表活也能让卡波姆慢慢变稠，两条路都能织网"

2.4 为什么怕盐？——网被"沙袋"压塌

分子机制（讲透它，你就能答任何盐相关问题）

配方里的盐（NaCl）电离出 Na⁺ 和 Cl⁻。Na⁺ 带正电荷，会跑去"中和"卡波姆链上的负电荷（-COO⁻）——相当于把电荷排斥屏蔽掉。网失去撑开的力 → 塌缩 → 粘度断崖式下降，甚至变回水。

为什么必然发生：卡波姆的增稠动力 100% 来自电荷排斥（中和增稠），电荷没了，网就散了。所以"怕盐"不是缺陷，是这种增稠机理的物理必然。

  • 敏感度：一般配方里盐含量超过 0.1~0.5% 就明显影响（具体视型号）
  • 注意：离子型表活（AES、LAS、氨基酸表活）自带离子，也会削弱卡波姆网络——所以"含表活体系"和"含盐体系"本质是同一类问题
  • 客户语言："盐离子像给渔网压上沙袋，网眼被压塌，水兜不住了。所以客户做含盐沐浴露、氨基酸洁面，不能直接上普通卡波姆。"
销售要点：客户说"卡波姆一加表活就变稀"——不是卡波姆质量问题，是配方含离子。解法只有两条：选疏水改性型（见 2.5），或换增稠思路。

2.5 疏水改性为什么耐盐？——多加了一把"油锚"

这是 FD20/21/2010/2020 的核心技术，也是你能讲出的最值钱的原理。

分子改造：在链上长出"疏水锚"

聚合时引入长链疏水共聚单体（甲基丙烯酸月桂酯、十六酯、十八酯等，即 C10-30 烷基丙烯酸酯）——分子链上除了羧基，还长出一段段不亲水的长烷基尾巴。

关键机制——疏水缔合：这些疏水尾巴在水里"怕水"，会像油滴一样互相抱团、勾在一起，形成物理交联点。于是网络的撑开有两种力：①电荷排斥（和普通卡波姆一样）；②疏水缔合（普通卡波姆没有）。

为什么耐盐：盐只屏蔽电荷排斥，屏蔽不掉疏水缔合。电荷没了，油锚还在勾着，网就不塌。

对比维度普通卡波姆（均聚物）疏水改性卡波姆结构根源
撑网的力只有电荷排斥电荷排斥 + 疏水缔合引入了 C10-30 烷基链
耐盐性差（盐一来就塌）强（1% NaCl 实证不塌）盐屏蔽电荷，但疏水缔合不受影响
与离子表活配伍差好（氨基酸体系也能用）同上
INCI 名CarbomerAcrylates/C10-30 Alkyl Acrylate Crosspolymer成分表可直接辨认
客户语言："普通卡波姆靠'电荷'撑伞，盐一来电就断；疏水改性卡波姆除了电荷，伞骨上还加了锁扣（油锚）——盐把电断了，锁扣还在，伞塌不了。"

2.6 为什么乙醇会让卡波姆变浑浊？——"泳池水"被换成了"酒"

做免洗消毒凝胶的客户一定会遇到：乙醇浓度高了（≥70~75%），凝胶发白、不透明。

分子机制（原理推断 ⚠，现象为 TDS/行业实证）

① 电荷撑不开：乙醇的介电常数（约 24）远低于水（约 80）——体系从"水的泳池"变成"酒的泳池"，极性大幅降低 → 羧基电离度下降 → 电荷排斥减弱 → 网撑不开。

② 链收缩聚集：乙醇对高分子链是较差的溶剂（去溶剂化）→ 链段收缩、局部聚集 → 光线散射 → 视觉上发白浑浊。

解法：选乙醇相容型卡波姆（天赐 TC-CARBOMER 351）——TDS 实测 70% 乙醇下透光率仍 ≥85%。其他普通卡波在醇基体系会浑浊，这是 351 的专属卖点。

  • 客户语言："乙醇浓度高了，等于把撑网的'电'抽走，网缩成一团，光一照就发白。要做透明的消毒凝胶，得用专门扛得住酒精的型号。"
  • 销售提示：客户问"为什么凝胶发白"——先用乙醇浓度 75% 这条常识接住，再推 351 对比样品，眼见为实。

2.7 为什么剪切变稀？——网"拆了还能装回去"

卡波姆凝胶最值钱的体验：搅拌时变稀，静止时恢复稠度（专业叫法：假塑性 / 触变性）。

状态分子层面客户感受
静止三维网络完整，链间交联点/缠结都在 → 高粘产品放着不流动、粒子不下沉
搅拌/涂抹剪切力拆开缠结、拉断部分交联点 → 粘度骤降生产好搅拌、涂抹顺滑不拉扯
恢复静止缠结和交联点重新形成（秒~分钟级）→ 粘度恢复涂完停在皮肤上不流淌
  • 三个卖点都从这里来：悬浮（静止够稠，珠光粉/磨砂粒子/防晒剂不下沉）· 施工（搅拌变稀，能耗低）· 肤感（涂抹顺滑，涂后定型）
  • 客户语言："像摇一摇的番茄酱——用力就稀，放着又稠回来"
  • 注意：过度/长时间高速剪切会"打废"——网络恢复需要时间，生产上要控制搅拌强度

2.8 短流 vs 长流：网眼密度的差异

卡波姆的"流变性格"分两派，这是选型的第一道分水岭。

性格分子根源剪断后表现适合做什么
短流（Short Flow）交联密度高，网络致密、结实"嘎嘣脆"——网一断就恢复，呈稠厚膏状凝胶、膏霜、牙膏类稠厚产品
长流（Long Flow）交联密度低，网络疏松、柔韧慢悠悠拉丝、流动，呈乳液/流体质感乳液、低粘悬浮、流动感产品
  • 天赐对照：常规系列 341/381 是仅有的长流；FD 系列 FD2010/2020 是长流耐盐版
  • 客户语言：短流=果冻质感，长流=蜂蜜拉丝
  • 销售提示：客户要"膏状稠厚感"推短流，要"清爽流动感"推长流——先问质地，再给牌号

卖卡波姆的 3 个底层逻辑

① 卡波姆是表活的"自然延伸"

客户买了你的表活，必然遇到增稠问题（含盐/透明/结块）。卖表活时问一句："增稠体系定了吗？有没有遇到过盐析、结块、不透明？"——卡波姆不是硬推，是帮客户解决配方痛点。

② 天赐卖的是"组合方案"

路博润只卖卡波姆，天赐表活+卡波姆一起卖。氨基酸表活难增稠 → CAB 协同 + 卡波姆双保险；无硫酸盐透明体系 → CAB 35TF + 340H/640 双透明。竞品给不了"清洁+增稠"一单打包。

③ 用原理建立信任，用数据收口

客户问"为什么"，你从分子层答（电荷撑网、油锚耐盐、乙醇去溶剂化）——客户觉得你懂行；然后马上用 TDS 数据收口（1% NaCl 实测 ≥4000、70% 乙醇 ≥85%、透光率 ≥95%）。原理立信任，数据促下单。

与表活的组合销售（牌号级）：常规个护 → CAB 35 + 380/FD980；无硫酸盐婴童 → CAB 35TF + 340H（无盐无苯双保险）；氨基酸体系 → 氨基酸表活 + CAB 35 + FD21（耐盐）；透明极致 → CAB 35TF + 640；免洗消毒凝胶 → 温和表活 + 351；口腔 → MAB 40LDL + 356；家居清洁 → CAB 35/氧化胺 + 276/396；ESG → RSPO 表活 + BIO 380。
