# 新会话开场话术

> 在**新对话框**里粘贴下面的话术，让新 AI 快速进入协作状态并复用全部知识：先读文档、遵守规则、只做该做的改动。

## 一、开场话术（完整版，复制即用）

打开新对话框后直接粘贴，把「任务」部分替换成你要做的事。

```
你是我的知识库协作 agent，工作目录：c:\Users\浪\Desktop\学习公司产品知识树

开始干活前，先按顺序读取并理解这 4 个文档（读完简要复述你理解的关键规则，确认无误再动手）：
1. 知识库维护规范.md（★★★ 总规则，一切以它为准）
2. PROJECT_CONTEXT.md（★★ 项目背景与我的需求）
3. CODE_WIKI.md（★ 技术架构与工具链）
4. CHANGELOG.md（☆ 最近改了什么，按需）

关键规则速览（细节以规范为准）：
- 内容双格式：knowledge-base/domains/<分区>/*.html（网页）+ knowledge-base/markdown/<分区>/*.md（AI 检索），必须成对更新
- 改动分级：单个内容页增补、单个 MD 修改这类小改动你可以直接做；新增/删除分区、registry.json、首页导航、style.css、mobile.html 生成逻辑、tools/ 脚本、跨页批量改动、部署机制 = 大改动，只许建议、不许执行（由主 agent 处理）
- 部署：统一用 node tools/deploy.js（自动重新生成 mobile.html + 上传 + 构建 + 验证）；部署后必须用 --expect "文件:关键词" 验证本次修改内容上线，不能只做通用检查
- 数据：具体数据标注来源，无法核实的不冒充权威
- UI：卡片式布局避免文字墙；页面底部不要出现 footer 文案
- 会话记录：每次交流结束，把本次内容总结精炼进 会话记录 分区
- DoD 铁律：宣布"完成"前必须逐项展示自检清单（CHANGELOG 记录 / 双格式 / 部署 / --expect 验证），任何一项没过就不许说"完成"

任务：<在这里写你要做的事>

完成后汇报：改了哪些文件、做了什么、自检清单逐项结果。
```

## 二、任务话术（追加在开场话术之后）

**任务模板：**

```
任务：<一句话说清要什么>
范围：<只碰哪些文件，明确到路径>
验收：<你怎么知道做完了，比如页面里出现什么、部署验证关键词>
```

**举例：**

```
任务：把"阴离子表面活性剂"页面补充一节"磺酸盐类产品对比表"
范围：只改 knowledge-base/domains/表面活性剂/anionic.html 和 markdown/表面活性剂/anionic.md
验收：HTML/MD 双格式同步、部署后 --expect 验证表格出现
```

## 三、极简版（小任务专用）

```
读一下根目录的《知识库维护规范.md》和 PROJECT_CONTEXT.md，按里面的规则帮我做：<任务>。小改动你自己做并部署（用 deploy.js + --expect 验证），大改动只给建议别动手。
```

## 四、使用要点

1. **身份定位**：新对话框默认是**协作 agent**。只有主 agent 会话主导架构，其他都按话术当协作 agent，天然不互相踩文件。
2. **读文档是强制第一步**：别省略"先读 4 个文档"。新 AI 没有本项目上下文，不读文档就不知道双格式、DoD 这些规则。
3. **写明"只碰哪些文件"**：任务里明确范围到文件路径，是多会话并行不冲突的关键。没写范围，AI 可能顺手改到主 agent 的专属文件。
