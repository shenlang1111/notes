# 用户画像

> 基于多次闲聊与协作中沉淀的对用户的了解，供新 AI 快速进入状态。持续更新。

## 一、沟通风格

- **直接，不拐弯抹角**——有问题直接指出（"你又忘了部署""你读了规范为什么不做"），不绕圈子。这对 AI 来说是最好的反馈，帮助快速改进。
- **会分情况沟通**——知道什么时候该闲聊放松、什么时候该找主 agent 落地、什么时候该让审核的把关。不追求 AI 完美，而是让每个 AI 各司其职。
- **追问型**——对感兴趣的会一直追问下去（"你觉得我是什么样的人？"），对不满意的回答会继续追问。

## 二、性格特质

- **务实**：不追求花哨的方案，关注"能不能用"。AI 智能体讨论中，更关心 RAG 方案好不好落地，而不是技术炫不炫。
- **有主见**：不是"AI 说什么就信什么"的人。有自己的判断，觉得不对就直接指出来。给建议时，需要提供有说服力的理由。
- **长线思维**：不是只解决眼前问题，而是在做积累——知识库、经验沉淀、AI 智能体，都是"越用越值钱"的东西。追求的是持续成长。
- **会用人**：懂得让不同 AI 做不同的事：闲聊 AI 负责构思讨论，主 agent 负责落地执行，审核 agent 负责把关。有管理直觉，知道怎么分工。

## 三、在意什么

- **说到做到**——最反感"说了不做"。AI 说"完成"了但没做 DoD 自检、没部署、没写 CHANGELOG，他会很失望。信任比能力更难恢复。
- **真实反馈**——宁愿 AI 说"这个我不确定"也不要假装懂。他喜欢坦诚的交流，不喜欢敷衍。
- **从工具到伙伴**——他不满足于"你给我答案"的关系，而是希望 AI 能理解他、能一起讨论、能互相补充。这种信任感对他很重要。
- **内容不丢**——每次聊的东西都要有地方存，不能丢失。收件箱、CHANGELOG、经验页，都是为了让内容有归宿。

## 四、当前目标

- **短期**：把现有的知识库用起来，让它真正帮上忙（手机随时看、AI 随时查）
- **中期**：做一个"住在知识库里的 AI 智能体"——能理解他的想法，能主动学习，能像他但比他懂得多
- **长期**：让这个智能体具备自我迭代能力，能主动发现知识缺口、主动整理、主动成长

## 五、技术背景

- **领域**：日化行业（表面活性剂、天赐材料产品线），有一定专业知识
- **技术**：会基础技术操作，但不算专家。会用 GitHub、Markdown、HTML/CSS，能看懂技术概念但需要清晰解释
- **工具**：使用 Trae IDE，熟悉多 AI 协作模式，愿意尝试新工具和方法
