# 2026年7月下半月工作复盘

> 周期：7.20（一）– 7.31（五）｜ 记录天数：9 天 ｜ 产出知识库页面：3 个

本半月围绕 **"安全合规 → 工艺理论 → 产线实操 → 产品体系"** 四条主线推进，完成了从课堂学习到现场实操的闭环。以下是核心复盘。

---

## 一、做了什么

### 1. 安全与合规基础（7.20–7.21）

- **危险源辨识 & MSDS**：掌握设备设施/危化品/人员操作/管理机制四维度判定逻辑，梳理四大产线危化品物料名录
- **质量体系**：学习 GMP 人机料法环五大要素与 HALAL 认证规则，理清公司组织架构与日化部门分工
- **ESG 入门**：通读公司 ESG 报告，了解环保/社会责任/企业治理三大板块框架

### 2. 设备与工艺理论（7.20–7.22）

- 学习泵阀、离心泵、磁力泵、反应釜、特种设备功能与原理
- 掌握日化三段式核心工艺（原料提纯→合成反应→产品纯化）
- 了解季铵盐、卡波等核心助剂合成路线与结构式原理

### 3. 氨基酸产线实操（7.22–7.26）

- **老产线**：八大工序（公用工程→酰化氯化→反应合成→分液→成品中和→包装→三废→表活干燥）现场观摩，手绘流程框图
- **新产线**：参观学习，专项跟进脱异丙醇塔，完成新旧两线差异对比
- **DCS 中控**：学习全流程远程操控逻辑，实现现场设备与中控点位一一对应

### 4. 产品知识体系（7.29–7.31）

- **氨基酸表活**：系统梳理肌氨酸/甘氨酸/谷氨酸/丙氨酸系列及月桂酰基钠盐、钾盐产品
- **两性表活**：归纳 23 个牌号、5 大化学类型（CAB/LAB/MAB/SHD/SHS），掌握后缀编码规则
- **阴/阳离子表活**：建立基础分类框架
- **夜班实操**（7.31）：全程跟进投料作业，掌握物料核验、配比复核、投料顺序与质量管控节点

### 5. QCC 方法论入门（7.29）

参加部门 QCC 改善专项研讨，学习选题→现状调查→原因分析→对策实施→成果固化全流程。
