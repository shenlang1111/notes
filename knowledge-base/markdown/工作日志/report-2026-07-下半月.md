# 2026年7月下半月工作复盘

> 报告周期：2026.07.20 – 2026.07.31 ｜ 填报人：天赐材料日化销售 ｜ 部门：日化事业部

## 一、本月工作概览

本报告期围绕 **安全合规 → 工艺理论 → 产线实操 → 产品体系** 四条主线系统推进，完成从课堂理论学习到车间现场实操的完整闭环。累计学习 9 天，覆盖安全、质量、设备、工艺、产品、QCC 六大模块，形成手写笔记 3 份 + 知识库产出 3 个主题页面。

| 维度 | 核心内容 | 天数 | 产出形式 |
|------|---------|:----:|---------|
| 安全合规 | 危险源辨识、MSDS、GMP、HALAL、ESG | 2 天 | 危化品名录、手写笔记 |
| 设备与工艺 | 化工通用设备原理、日化三段式工艺、助剂合成 | 2 天 | 手写笔记 |
| 产线实操 | 氨基酸老线八大工序、新线参观、DCS 中控 | 3 天 | 流程框图（手绘）、新旧线对比台账 |
| 产品知识 | 氨基酸表活、两性/阴/阳离子表活分类、牌号规则 | 2 天 | 知识库页面 3 个 |
| QCC 方法论 | 选题→现状调查→对策→固化全流程 | 1 天 | 学习记录 |

## 二、重点工作完成情况

### 2.1 安全与合规基础（7.20–7.21）

- **危险源辨识与 MSDS 专项培训**：掌握设备设施/危化品/人员操作/管理机制四维度判定逻辑，观看典型化工事故警示视频，了解危险等级划分标准与个体防护实操要求
- **危化品物料管理**：逐条梳理卡波、阳离子调节剂、氨基酸、两性表活四大产线全套危化品物料名录
- **质量体系学习**：公司组织架构与日化部门分工；GMP 人机料法环五大核心要素；HALAL 清真认证规则；日化行业各类认证及公司现有资质
- **ESG 入门**：通读公司 ESG 报告，了解环保、社会责任、企业治理三大板块框架

### 2.2 设备与工艺理论（7.20–7.22）

- **化工通用设备**：泵阀、离心泵、磁力泵、反应釜、特种设备等功能与基础原理
- **日化核心工艺**：三段式工艺路线（原料提纯 → 合成反应 → 产品纯化）
- **助剂合成逻辑**：季铵盐、卡波等核心助剂的合成路线、化学反应要素与结构式原理

### 2.3 氨基酸产线现场实操（7.22–7.26）

**老氨基酸产线（7.23–7.25）：**
- 沿动线观摩八大系统全套设备（公用工程 → 酰化氯化 → 反应合成 → 分液操作 → 成品中和 → 包装 → 三废处理 → 表活干燥）
- 手绘产线简易流程框图，记录设备安装位置与上下游衔接关系
- DCS 中控室学习全流程远程操控逻辑，确认八大工段关键设备监控点位、运行参数与启停管控

**新氨基酸产线（7.26）：**
- 参观新线整体工艺流程与工段排布方式
- 专项学习新增核心设备脱异丙醇塔的布设位置、介质处理目的与工艺作用
- 完成新旧两条产线设备构成、流程架构的差异对比

### 2.4 产品知识体系搭建（7.29–7.31）

- **氨基酸表活系列**：系统梳理肌氨酸、甘氨酸、谷氨酸、丙氨酸及月桂酰基钠盐、钾盐等全品类产品
- **两性表活**：归纳 23 个牌号、5 大化学类型（CAB/LAB/MAB/SHD/SHS），掌握牌号命名规则与后缀编码含义（HP 膏状 / FA 增泡 / TF 无盐专利 / B 缓冲 / LS 低盐 / H 高粘 / HG 凝胶 / FO 低气味 / NF 无添加 / RSPO MB 可持续认证）
- **阴/阳离子表活**：建立基础分类框架，对应公司主力产品牌号
- **夜班投料实操**（7.31，20:00–次日 8:00）：全程跟进投料作业，熟悉物料核验、配比复核、投料顺序及现场操作规范，掌握投料精度控制、安全操作与质量管控节点

### 2.5 QCC 方法论入门（7.29）

参加部门 QCC 改善专项研讨，系统学习选题 → 现状调查 → 原因分析 → 对策实施 → 成果固化完整流程及各阶段交付资料要求。

### 4.2 经验总结

- **学习路径验证有效**：安全 → 设备 → 工艺 → 产线 → 产品的递进式学习路径，每步都在为下一步打基础，后续可复用此框架
- **课堂+现场联动效果好**：理论课上学了原理，去产线看到实物，再上 DCS 中控看远程控制——同一知识点从三个维度反复印证，记忆深刻
- **知识库沉淀价值高**：产出的 3 个页面可长期复用，后续学习成果持续补充即可，避免重复造轮子
