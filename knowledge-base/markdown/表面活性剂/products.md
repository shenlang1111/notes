# 天赐产品全对照

### 按分类对照

| 表活分类 | 教材代表品种 | 天赐对应产品 | 产品定位 |
| --- | --- | --- | --- |
| **阴离子-羧酸盐** | N-酰基氨基酸盐 | **Napure系列**（C-FA, C-FG等） **AMIN系列**（GCK95U(P), CG30, SCI85, SCG等） | 高端氨基酸表活，温和清洁主表活 |
| **阴离子-硫酸酯盐** | K12(SDS), AES | —（但客户配方中常与天赐产品复配） | 了解竞品（AES是洗发水最常用主表活） |
| **阳离子** | 季铵盐, 聚季铵盐(PQ-6/7/10) | **聚季铵盐系列** | 护发素、发膜调理成分 |
| **两性-羧基甜菜碱** | CAB | **TC-CAB 35/35TF/30/97** | 通用增泡稳泡+协同增稠 |
| **两性-羧基甜菜碱** | LAB | **TC-LAB 35/35TF** | 高端温和，婴童/洁面 |
| **两性-磺基甜菜碱** | 椰油酰胺丙基羟基磺基甜菜碱 | **TC-SHD系列** | 温和低刺激，耐硬水，pH宽域稳定 |
| **两性-咪唑啉型** | 月桂基两性醋酸钠 | **TC-MAB 40LDL** | 极温和，婴童二合一，弱抑菌 |
| **非离子-多元醇型** | APG | **TC-APG系列** | 绿色天然，增泡增效 |
| **两性-氧化胺型** | 氧化胺 | **TC-CAO, TC-LAO** | 增泡增稠稳泡，调理抗静电 |


### 经典配方中的表活角色映射

| 配方角色 | 表活类型 | 天赐产品 | 教材知识点 |
| --- | --- | --- | --- |
| 主表活（清洁+起泡） | 阴离子 | Napure C-FA / SCI85 / GCK30P | 阴离子表活-羧酸盐型 |
| 辅表活（增泡+稳泡+降刺激） | 两性 | TC-CAB 35 / TC-LAB 35TF / TC-SHD | 两性表活-甜菜碱型、磺基甜菜碱 |
| 增泡增稠剂 | 两性 | TC-CAO / TC-LAO | 两性表活-氧化胺型 |
| 温和增效剂 | 非离子 | TC-APG | 非离子表活-多元醇型(APG) |
| 调理剂 | 阳离子 | 聚季铵盐系列 | 阳离子表活-季铵盐/PQ系列 |
| 增稠剂 | —（非表活） | TC-CARBOMER系列 | 非本章内容，但与表活体系密切相关 |
