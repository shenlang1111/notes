# 客户问题诊断

> 粘度不够、泡沫问题、浑浊沉淀、刺激性强、防腐失效——五大常见问题的根因→排查→方案→话术。


> **[accent]**
> **作为销售，你的价值在于帮客户解决问题**  
> 
> 以下是日化配方师最常遇到的五大技术问题。理解每个问题的**根因→排查顺序→解决方案**，你就能在客户遇到问题时给出专业建议，建立信任。

### 15.1 "粘度不够 / 冬天掉粘"

| 根因 | 排查方法 | 解决方案 |
| --- | --- | --- |
| **盐曲线未到峰值**——AES体系增稠呈"钟形"曲线，盐过少或过多都导致粘度低 | 做盐曲线实验：从0.5%到2.0%，每0.1%递增测试粘度 | 找到峰值粘度对应的NaCl用量（通常0.5-2.0%） |
| **温度敏感性**——冬天温度从25°C降至10°C，粘度可能下降30-50% | 测量25°C→10°C粘度变化 | 复配疏水型与亲水型增稠剂，或加入0.3-0.5% CMEA做温度补偿 |
| **无硫酸盐体系难增稠**——氨基酸表活加盐直接析出，无粘度峰值 | 确认是否无硫酸盐体系 | **优先推荐CAPB占总表活30-50%做协同增稠**；或月桂酰肌氨酸钠:CAPB≈1:1 |
| **过盐返稀**——盐过量导致胶束结构失稳 | 检查NaCl总量是否超2% | 用水稀释或减少盐用量 |


> **[accent]**
> **推荐话术：**"您这个体系的主要增稠依赖AES盐曲线，建议先做盐曲线实验确定最佳盐点。另外冬天可以考虑加0.3-0.5%的CMEA做温度补偿。如果是无硫酸盐体系，建议用CAB占总表活30-50%做协同增稠——天赐的TC-CAB 35在这个体系里效果非常稳定。"**→ 直接关联天赐产品**

### 15.2 "泡沫不够丰富 / 持久"

| 根因 | 排查方法 | 解决方案 |
| --- | --- | --- |
| **主表活不足** | 计算AES/氨基酸表活在总表活中的占比 | 增加AES至12-15%或氨基酸表活至15-20% |
| **稳泡剂不足** | 检查CMEA/CDEA/氧化胺用量 | 加入1-2% CMEA，或CAB增至6% |
| **油脂/硅油抑泡** | 检查调理剂/硅油添加量 | 先用两性/非离子表活将油脂乳化增溶 |
| **硬水消泡** | 检测水质硬度 | 加入0.1-0.2% EDTA二钠；选用耐硬水表活（牛磺酸盐、肌氨酸盐） |
| **泡沫粗糙不细腻** | 评估泡沫质感 | 加入3-5%椰油酰谷氨酸二钠，泡沫细腻绵密 |


> **[accent]**
> **推荐话术：**"泡沫丰富度是AES+CAB的基础能力，泡沫持久性靠CMEA和CAB的稳泡作用。如果泡沫不够细密，建议加入3-5%的椰油酰谷氨酸二钠——天赐CG30W在这个场景下表现非常好，能显著提升泡沫细腻度和稳定性。"**→ 直接关联天赐产品**

### 15.3 "洗后干涩 / 紧绷"

| 根因 | 排查方法 | 解决方案 |
| --- | --- | --- |
| **过度脱脂**——表活体系清洁力过强，皮肤天然油脂被过度洗去 | 计算总表活活性物含量，评估表活刺激性 | 降低AES至8-10%，增加氨基酸表活至8-15%，总表活活性物≤15% |
| **调理剂不足** | 检查PQ-10、瓜尔胶、硅油等调理剂添加量 | 加入0.1-0.3% PQ-10做调理，2-5%甘油做保湿 |
| **假滑（表活残留）**——CAB冲洗不净产生滑腻感 | 降低CAB后测试冲洗感 | 降低CAB至3-4%，增加APG用量（APG改善冲洗清爽感） |
| **真滑不足**——调理剂沉积不够 | 评估洗后触感 | 加入0.5-1.5%硅油乳液+0.1-0.3%阳离子瓜尔胶共沉积 |


> **[accent]**
> **推荐话术：**"干涩紧绷本质是过度脱脂。建议把一部分AES换成氨基酸表活——椰油酰谷氨酸二钠的脱脂力远低于AES，洗后肤感柔软滋润。再搭配0.2%的PQ-10做调理，问题基本解决。天赐的CG30W和GCK30P都是针对这个场景的。"**→ 直接关联天赐产品**

### 15.4 "产品变色 / 变味"

| 根因 | 排查方法 | 解决方案 |
| --- | --- | --- |
| **金属离子催化氧化**——铁>0.1ppm即可引起明显变色 | 检测生产用水电导率（应<5μS/cm） | 加入0.05-0.2% EDTA二钠螯合；使用去离子水 |
| **美拉德反应**——甘氨酸盐在pH偏高+>80°C长时间加热变黄 | 检查生产温度是否超80°C | 中和后将温度降至<60°C再加入其他成分 |
| **防腐失效**——微生物繁殖导致霉变 | 做防腐挑战测试 | 选用非离子型防腐剂（苯氧乙醇+乙基己基甘油，约1%） |
| **光照降解** | 检查包装是否透明 | 使用UV吸收剂；避免透明瓶装 |


> **[accent]**
> **推荐话术：**"变色问题90%是金属离子催化的氧化反应。建议加0.1%的EDTA二钠做螯合剂，成本极低但效果立竿见影。另外检查一下生产用水的电导率——去离子水是基本要求。天赐的TF系列（无盐技术）从源头减少了金属离子残留，对防止变色也有帮助。"**→ 直接关联天赐产品**

### 15.5 "透明度不够 / 浑浊"

> **[accent2]**
> **三步排查法**  
> 
> **第一步：查pH**——低于5.0容易析出浑浊（椰油酰谷氨酸钠在pH<5时酸式析出）。保持pH≥5.0，使用TEA盐型代替钠盐提高溶解度和透明度。
> **第二步：查阳离子调理剂**——PQ-10等阳离子物控制在总阴离子量的10%以下。微调pH至略偏酸让阴离子部分质子化，降低结合力。
> **第三步：查盐含量**——NaCl总量≤2%。先做盐曲线确定上限。加入3-5%丙二醇/甘油防低温浑浊。
> 
> 三步排查完，90%的透明度问题都能找到。
