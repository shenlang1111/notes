## 一、阴离子表面活性剂 — 天赐Napure与AMIN系列详解

阴离子表面活性剂在水中电离后，亲水头基带**负电荷**。它们是洗护产品中最主要的清洁成分，负责**去污、起泡、乳化**三大核心功能。天赐的阴离子表活以**氨基酸类**为核心，包含Napure（天然纯净）和AMIN（氨基酸）两大品牌线，覆盖六大氨基酸子类、超过30个牌号，是国内品类最全的氨基酸表活供应商。

## 二、阳离子表面活性剂 — 调理与抗静电专家

阳离子表面活性剂在水中电离后，亲水头基带**正电荷**。由于头发和皮肤表面在正常pH下带负电荷，阳离子表活可以通过**静电吸附**牢固地附着在表面，提供**抗静电、柔软、顺滑、调理**四大功效。是护发素、发膜、衣物柔顺剂的核心成分。**注意：不能与阴离子表活直接混合使用**（会形成沉淀），必须在配方中分区或分步加入。

### 阳离子表活的作用机理

- **电荷吸附机制：** 头发角蛋白的等电点约为pH 3.67，在洗发水pH（5.5-6.5）下，头发表面带**负电荷**。阳离子表活的季铵正电头基与头发的负电位点产生**离子键结合**，形成一层疏水性润滑膜。
- **沉积与铺展：** 阳离子表活分子在头发表面优先沉积在**受损区域**（毛鳞片翘起处），因为受损区域暴露更多负电荷位点。
- **季铵盐结构：** 阳离子表活的活性中心是**季铵基团（-N+R3）**，无论pH如何变化都保持正电荷。疏水链长度（C16-C22）决定了调理效果的持久性。
- **与阴离子表活的配伍禁忌：** 阳离子和阴离子表活混合会形成**不溶性复合物沉淀**。通过**胶束隔离**策略解决，或使用聚季铵盐类（高分子型阳离子）。

## 三、非离子表面活性剂 — 稳定与绿色的"万能胶"

非离子表面活性剂在水溶液中**不电离**，亲水头基是多个醚键（-O-）或羟基（-OH），通过氢键与水分子结合。这使得非离子表活具有**三大独特优势**：①不受pH影响；②**耐硬水**；③与所有类型表活完全相容。非离子表活被称为"绿色"表活，其中APG（烷基糖苷）是典型代表。

### 非离子表活的特点

- **不受pH影响：** 在任何pH（2-13）条件下都保持同一分子形态，是**极端pH配方**的唯一选择。
- **耐硬水：** 不与钙镁离子反应，不会形成"皂垢"，在硬水地区清洁力不受影响。
- **与所有表活相容：** 不带电荷，可作为**"桥梁"**连接阴离子和阳离子表活。
- **浊点现象：** 温度升高到浊点以上时，氢键断裂，非离子表活从水中析出。APG的浊点通常>100°C，使用范围最广。

### APG（烷基糖苷）— 天赐的"绿色明星"

APG（Alkyl Polyglucoside）= 天然葡萄糖 + 天然脂肪醇，原料100%来自可再生资源（玉米淀粉+椰子油/棕榈仁油），28天生物降解率>95%。

**APG的四大优势：**
① **极致温和**——对眼睛和皮肤刺激性极低，可用于婴童无泪配方；
② **泡沫细腻**——泡沫细腻稳定，带来"奶油般"的洗感；
③ **耐硬水耐酸碱**——在pH 2-13均稳定，硬水中不产生沉淀；
④ **协同增效**——与阴离子和两性表活复配时，能显著降低整体刺激性。

**非离子表活的核心使用原则：** 在个人护理产品中，非离子表活通常作为**第三辅助表活**，用量1-3%，主要作用是增溶香精、调节冲洗感、降低整体刺激性。在家居清洁产品中，非离子表活可以作为**主表活**，用量5-20%。

## 四、两性表活：TC-CAB / LAB / SHD / MAB 全系列

两性表面活性剂在同一分子中**同时含有正电荷和负电荷基团**。天赐的两性表活覆盖**甜菜碱、磺基甜菜碱、咪唑啉**三大子类（氧化胺作为特殊类型列出），其中CAB国内市占率**29.7%**行业第一（来源待核实）。

### 甜菜碱的详细分类

- **烷基甜菜碱：** 最简单的甜菜碱结构，主要用于工业清洗和低端日化。
- **酰胺丙基甜菜碱（CAPB）：** **最主流**的甜菜碱类型。天赐TC-CAB和TC-LAB均属此类。
- **磺基甜菜碱（Sultaine）：** 阴离子基团由羧酸根替换为**磺酸根**，在更宽pH范围内保持稳定。天赐TC-SHD系列即属此类，是婴童配方的首选。
- **咪唑啉型两性表活：** 以咪唑啉环为亲水头基，**极致温和**，常用于婴童无泪配方。天赐TC-MAB系列即属此类。

### 氧化胺的特殊说明

氧化胺在化学结构上属于非离子表活（N→O极性键不电离），但在酸性条件下质子化后表现为阳离子特性。由于其在配方中常与两性表活一起发挥增泡稳泡、协同增稠的作用，且行业习惯上将其归入两性类别讨论，本页在"两性"章节中仅作为特殊类型列出。天赐的TC-CAO/TC-LAO系列在正式品类归档中归入非离子表活。

### 4.1 甜菜碱类（Betaine）— 天赐最核心的两性表活

## 五、配方实战：表活怎么搭配

### 5.1 配方设计核心原则

| 原则 | 说明 |
| --- | --- |
| **主表活+辅表活** | 阴离子做主表活（清洁），两性离子做辅表活（降刺激+增泡），非离子做第三辅助（增溶+稳定） |
| **C还是L？** | C（椰油基）= 性价比 + 通用性，L（月桂基）= 更温和 + 起泡更快 + 更高端 |
| **30还是95？** | 30%（液体）= 直接添加；95%（粉末）= 高浓度，固体配方 |
| **TF还是标准？** | TF（无盐）= 极简配方 + 婴童 + 敏感肌；标准版 = 常规配方，性价比更高 |
| **pH匹配** | 甘氨酸钾在碱性条件下做透明产品，在酸性条件下做膏体；谷氨酸在弱酸性体系使用 |

### 5.2 典型配方框架

**氨基酸洁面膏（弱酸性洁面）**：主表活 AMIN GCK95U(P) 15-25%，辅表活 TC-CAB 35TF 2-5%，保湿甘油/丙二醇 10-20%，APG 0.5-2%，pH用柠檬酸调至弱酸性。

**无硫酸盐透明洗发水（高端透明体系）**：主表活 Napure L-FG90 15-25%，辅表活 TC-CAB 35TF 3-5%，TC-LAB 35TF 2-3%，卡波姆 0.2-0.5%，JR-400 0.2-0.5%。

**婴童洗发沐浴二合一（无泪温和配方）**：TC-CAB 35TF 8-15%，TC-SHD(L) 3-5%，AMIN LS30-NP 3-5%，APG 1-3%，甘油/泛醇 3-5%，无硫酸盐、无SLS/SLES。

**温和沐浴露（大众温和配方）**：Napure C-FA 10-20%，TC-CAB 35 3-8%，AMIN CG30 3-5%，NaCl适量增稠，pH 5.5-6.5。

**洁面慕斯（泡沫型洁面）**：AMIN GCK95U(P) 8-12%，AMIN CG30 4-6%，TC-CAB 35TF 2-3%，TC-MAB 40LDL 1-1.5%，APG 0.5-1%。

**合成香皂/洗发饼（固体清洁产品）**：Napure SCI85 20-35%，Napure C-FG 5-10%，TC-CAB 97 2-5%，填充淀粉/滑石粉，固体成型。
