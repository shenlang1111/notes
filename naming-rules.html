第 1 部分 · 表活命名：TC- + 系列 + 浓度 + 后缀

天赐两性/非离子表活牌号由四段组成：TC-（天赐）+ 化学系列 + 活性物浓度 + 后缀编码。后缀是选型的关键密码——读懂后缀，就知道这个牌号适合什么配方场景。

TC- + <化学系列> + <活性物浓度> + <后缀>　　例：TC-CAB 35TF = 天赐 + 椰油酰胺丙基甜菜碱 + 35% + 无盐

命名四段拆解

段落含义示例说明

系列代号化学系列/结构前缀CAB / LAB / MAB / SHD / SHS / CAO决定产品属于哪个化学系列
浓度活性物百分含量35 / 40 / 45 / 97数字代表活性物最低含量

第 2 部分 · 卡波姆命名：独立体系（不走表活结构）

卡波姆是独立命名体系，不走"TC- + 系列 + 浓度 + 后缀"结构：TC- + 品类标识（CARBOMER / BIO-CARBOMER）+ 牌号数字；FD 系列在数字前加 FD。

TC- + <品类标识> + <牌号数字>　　例：TC-CARBOMER FD21 = 天赐 + 卡波姆 + 疏水改性耐盐（易分散）

前缀 / 品类标识

前缀全称含义代表产品
CARBOMER卡波姆交联聚丙烯酸树脂（传统型 + FD 型）TC-CARBOMER 380
BIO-CARBOMER生物基卡波姆生物基版（95% 生物质、ISCC+ 认证、1:1 替换传统卡波 ⚠待核实）TC-BIO-CARBOMER 380
FDFast Dispersible快速分散（官网实锤）：自润湿、免浸泡/高速剪切FD10 / FD20 / FD21 / FD980 / FD2010 / FD2020

后缀 H（340H 的特殊后缀）

  • H（如 340H）：⚠推测 = 无苯/安全版。340H 与 340 粘度/透光率几乎一致，核心差异在溶剂体系（340 残留苯 ≤0.50% vs 340H 乙酸乙酯/环己烷无苯）→ 逻辑与 341↔381 同构，印证天赐"一牌号双溶剂"策略 ⚠推测。

规律（⚠推测待核实）

"一牌号双溶剂"策略：340↔340H、341↔381 为同配方出"苯系 / 无苯"双版本 → 出口、婴童、安全敏感客户推无苯版。⚠ 上述推测已登记待核实清单 #46-52（380↔980、FD2010↔Ultrez 20、FD21↔Ultrez 21、H 后缀、双溶剂策略、BIO 380 替换性、FD980 耐盐性），对外引用需谨慎，具体以天赐官方资料为准。
