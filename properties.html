7.1 CMC（临界胶束浓度）

定义

表面活性剂在溶液中开始大量形成胶束的最低浓度。低于CMC时，表活以单分子形式存在；高于CMC后，表面张力不再明显下降，多余分子形成胶束。CMC处，溶液的多种性质（表面张力、电导率、渗透压、去污力、增溶量）发生突变。

浓度 (c) → CMC
低于CMC → 高于CMC：
· 表面张力 → 不再下降
· 电导率 → 斜率突变
· 去污力 → 急剧上升
· 渗透压 → 趋于平缓

单分子态 → 界面吸附　｜　胶束态 → 增溶/去污

图解：CMC是表面活性剂性能的"分水岭"。低于CMC时，表面张力随浓度增加而下降，但去污力很低；高于CMC后，表面张力不再下降，但去污力和增溶量急剧上升。这是因为胶束形成后，油污可以被包裹在胶束内部带离。这就是为什么配方中的表活用量必须高于CMC——否则洗不干净。

7.2 HLB值（亲水亲油平衡值）

HLB值与应用对照

HLB 1~3 → 消泡剂　（消泡·亲油为主）
HLB 3~6 → W/O乳化　（油包水）
HLB 7~9 → 润湿　（润湿渗透）
HLB 8~18 → O/W乳化　（水包油）
HLB 13~15 → 洗涤　（洗涤去污）
HLB 15~18 → 增溶　（增溶·亲水为主）

7.3 Krafft点与浊点——一对"温度开关"

特征Krafft点浊点
适用表活离子型非离子型（PEO类）
温度变化方向升温→变澄清升温→变浑浊
物理本质溶解度达到CMC，胶束大量形成氢键断裂，EO链脱水→表活析出
实际意义使用温度下限——低于此温度表活以晶体析出使用温度上限——超过此温度表活"失效"
关键影响因素疏水链越长→Krafft点越高；加EO→Krafft点降低EO数越大→浊点越高；加盐→浊点降低
销售实战：客户说"CAB 35冬天粘度掉得厉害"。注意：CAB（椰油酰胺丙基甜菜碱）是两性表活，水溶性极好，其Krafft点通常远低于0℃，冬季常温下并不会"低于Krafft点"——低温问题不应归因到Krafft点上。低温下粘度或状态变化的常见真因是配方中其他组分的相行为变化：油脂或盐分低温结晶析出、非离子组分受浊点影响、低温凝胶化等。你可以建议客户：① 先排查储存温度与配方组分（油脂/盐含量、是否含易低温析出的组分）；② 复配助溶剂或抗冻组分（如醇类、丙二醇）改善低温稳定性；③ 控制运输与储存温度，避免长期低温存放。

7.4 CMC的测定方法详解

方法原理适用类型优点缺点
表面张力法γ-lgc曲线在CMC处转折所有类型最经典、最普适极低CMC时转折不明显；杂质干扰
电导率法κ-c曲线在CMC处斜率突变仅离子型操作简便、快速、设备成本低非离子型不适用；高CMC时转折不明显
荧光探针法芘的I₁/I₃比对微环境极性敏感，CMC处急剧下降所有类型灵敏度极高（μL级），适用于极低CMC需要荧光分光光度计
光散射法CMC以上胶束形成使散射光强度急剧增加所有类型可同时获得胶束大小和聚集数设备昂贵
ITC法测量胶束化过程的微量热效应所有类型可获得完整热力学参数(ΔG,ΔH,ΔS)设备昂贵，数据分析复杂

7.5 HLB值的计算方法

Griffin法（非离子专用）

对聚氧乙烯型非离子表活：HLB = E/5　（E为PEO链段质量百分数）
对多元醇脂肪酸酯：HLB = 20×(1−S/A)　（S为皂化值，A为脂肪酸酸值）

简单快速，但仅适用于特定类型。

Davies法（基团贡献法，通用）

HLB = 7 + Σ(亲水基常数) + Σ(亲油基常数)

适用于所有类型（含离子型），从分子结构直接计算。例如：-SO₄Na: +38.7，-COONa: +19.1，-OH: +1.9，-CH₂-: -0.475，-CH₃: -0.475

混合HLB计算：
HLB混合 = (W₁×HLB₁ + W₂×HLB₂ + ...) / (W₁ + W₂ + ...)
这就是配方师调节乳化体系HLB的核心方法——通过Span/Tween按比例混合，精确匹配油相所需的HLB值。
