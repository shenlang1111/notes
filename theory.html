一、基础概念与原理

表面活性剂（表活）最根本的结构特征是两亲性（amphiphilic）：一个分子同时含亲水基和疏水基。表活 = 一手抓油、一手抓水的分子，所有功能都从"两亲结构"长出来。

核心主线：两亲结构 → 决定表活所有行为 → 按亲水基电性分为四类 → 每类合成方法不同 → 表现为 CMC/HLB 等参数差异 → 最终决定应用场景。

① 两亲结构

分子同时含亲油基（直链烷基 C12-C18）和亲水基（-SO₃⁻、-COO⁻、-N⁺(CH₃)₃ 等）。碳链越长 → CMC 越低 → 表面活性越强（Traube 规则）。由此长出四大功能：清洁去污、起泡、乳化、增稠。

② 胶束与 CMC

浓度低于 CMC 时表活在界面定向排列，表面张力急剧下降；浓度超过 CMC 后多余分子自发抱团形成胶束（亲油基向内、亲水基向外），界面张力不再降，开始增溶去污。CMC 处电导率、渗透压、去污力发生突变。

③ CPP 堆积参数

决定胶束形态的"几何密码"。P = v / (a₀·lc)，P 越大胶束越扁平：球形 P<1/3、蠕虫状 1/3~1/2、层状 1/2~1。头基面积 a 减小（如加盐、复配异电性表活）→ P 增大 → 球形变蠕虫状 → 粘度急剧上升。

④ 定向排列与熵驱动

胶束形成是熵驱动的物理自组装：疏水尾链破坏水分子氢键网络，水分子被迫形成有序"冰山结构"；尾链抱团后释放被束缚的水分子，溶剂熵剧增 → ΔG<0 自发发生。是水分子想恢复自由，推着表活自动成胶束。

CPP 堆积参数 — 胶束形态对照

P = v / (a₀ · lc)　　v = 疏水尾链体积 · a₀ = 亲水头基有效面积 · lc = 尾链最大有效伸展长度
P 范围分子形状形成结构典型实例
P ≤ 1/3锥形（头大尾小）球形胶束SDS、低浓度 CTAB、氨基酸表活稀溶液
1/3 < P ≤ 1/2截顶锥形/楔形棒状/蠕虫状胶束AES+CAB 复配、CTAB+NaCl
1/2 < P < 1截顶锥形（头尾相近）层状结构、囊泡卵磷脂、双尾链表活
P ≈ 1圆柱形平面双分子层生物膜脂质
P > 1倒锥形（头小尾大）反胶束（非极性溶剂）AOT 在有机溶剂中
销售极简版：表活单独溶于水，周围的水被强行固定，体系不稳定；为了让水重新自由流动，疏水尾主动抱团成胶束，释放被束缚的水分子。是水分子想恢复自由，推着表活自动形成胶束。面对非技术客户，用"空心防水小气球"类比比讲热力学有效一百倍。

二、四大表面活性剂分类

按亲水基在水中是否电离及电性分类（最重要、最实用的分类法）。洗衣粉（LAS）、洗洁精（AES）、牙膏（K12）、洗发水（氨基酸表活）——日常清洁产品的主表活几乎都是阴离子型。

三、核心物化性质

CMC、HLB、Krafft 点、浊点——四个关键参数决定表活在配方里的角色。数值为教材通用参考值，产品具体参数以 TDS 与实测为准。

CMC 临界胶束浓度

表活开始大量形成胶束的最低浓度。低于 CMC 洗不干净，高于 CMC 才开始增溶去污。CMC 越低 → 配方成本更低、温和性更好。你卖表活，本质上卖的是"形成胶束的能力"。

HLB 亲水亲油平衡值

决定表活用途的"身份证"：1~3 消泡、3~6 W/O 乳化、7~9 润湿、8~18 O/W 乳化、13~15 洗涤、15~18 增溶。混合 HLB = Σ(Wi×HLBi)/Σ(Wi)，是配方师调节乳化体系的核心方法。

Krafft 点（离子型）

离子型表活的使用温度下限。低于此温度以晶体析出。疏水链越长 → Krafft 点越高；加 EO → 降低。甜菜碱 Krafft 点通常远低于 0°C，冬季常温不会"低于 Krafft 点"。

浊点（非离子型）

非离子 PEO 类的使用温度上限。升温 → 氢键断裂、EO 链脱水 → 表活析出浑浊。EO 数越大 → 浊点越高；加盐 → 降低。超过浊点表活"失效"。

四、合成工艺

核心心法：工艺决定论。合成工艺不只是"实验室配方"，而是决定产品纯度、色泽、副产物、刺激性的核心因素。天赐在氨基酸表活和两性表活上能建立品质优势，根本原因是对关键工艺参数（摩尔比/温度/时间）的系统优化。同样的"化学名称"背后，产品品质可以天差地别。

LAS（烷基苯磺酸钠）— 三步法

1
烷基苯制备：正构烷烃 → 脱氢/氯化 → 与苯烷基化（Friedel-Crafts，AlCl₃ 或 HF）→ 直链烷基苯（LAB）。
2
磺化：LAB + SO₃ → 烷基苯磺酸。膜式磺化反应器（降膜式），40-60°C，SO₃/LAB 摩尔比 1.05-1.10。
3
中和：磺酸 + NaOH → LAS 成品（脱色、调配）。

AES（脂肪醇聚氧乙烯醚硫酸盐）— 三步法

1
乙氧基化：ROH + 2~3EO → AEO。催化剂 KOH/NaOH，120-180°C，0.2-0.5 MPa。
2
硫酸化：AEO + SO₃ → 硫酸酯。30-50°C（比 LAS 更低，硫酸酯键高温易水解）。关键控制：副产物二噁烷残留量 ≤30 ppm。
3
中和：硫酸酯 + NaOH → AES；若用氨水中和 → AESA（更温和，高档香波用）。中和温度 <40°C。

甜菜碱（CAB/LAB）— 一锅法 · 天赐核心工艺

脂肪叔胺 + 氯乙酸钠 → 水溶液一步反应（季铵化+羧甲基化）→ 直接生成甜菜碱
1
中间体制备：脂肪酸（椰油/月桂）与 N,N-二甲基丙二胺缩合 → 酰胺叔胺中间体。
2
一锅法季铵化：酰胺叔胺 + 氯乙酸钠 → 70-90°C，pH 8-10，4-6 小时 → 甜菜碱成品。
3
纯化（天赐差异化）：无盐技术（TF 系列）去除 NaCl 副产物，游离胺控制 ≤0.3%（行业 1.0-2.0%）。
销售价值：普通 CAB 游离胺 1.0-2.0%，胺味明显；天赐 ≤0.3%，几乎无胺味。客户问"为什么你们的 CAB 贵一点"——答案就在这 0.7% 游离胺差异：更低游离胺 = 更温和肤感 = 更少胺味 = 更高品质。

氨基酸表活 — Schotten-Baumann 反应（天赐最核心平台）

R-COCl + H₂N-CHR'-COONa + NaOH → R-CO-NH-CHR'-COONa + NaCl + H₂O
温度 10-30°C（低温控制）· pH 9-11（碱维持）· 水-丙酮混合溶剂
1
酰氯制备：脂肪酸 + 氯化剂 → 脂肪酰氯。天赐自建脂肪酸精炼产线，从源头控制酰氯品质。
2
Schotten-Baumann 缩合：酰氯 + 氨基酸盐（肌氨酸钠/谷氨酸钠/甘氨酸钾）→ 低温 10-30°C 缩合，持续加 NaOH 维持 pH 9-11。
3
中和精制：精密中和 + 脱色 + 过滤。三种代表：肌氨酸钠（Napure C-FA）、谷氨酸盐（CG30W）、甘氨酸盐（GCK30P）。

五、应用原理

乳化、增溶、洗涤去污、泡沫、复配协同——表活理论最终落地到应用场景。没有单一表活能同时满足全部性能，必须多组分复配协同。

① 乳化理论

乳液是两种不相溶液体通过乳化剂形成的热力学不稳定但动力学稳定的分散体系。O/W（水包油）需 HLB 8~18，清爽易稀释；W/O（油包水）需 HLB 3~6，油腻滋润。DLVO 理论：Zeta 电位绝对值 >30mV 为稳定。

② 增溶作用

胶束空腔装油污、香精、油溶性原料。四种方式：PEO 链间缠绕（最高）> 栅栏层 > 胶束内核 > 表面吸附（最低）。增溶最佳 HLB 范围 15~18。增溶是胶束最核心的客户价值。

③ 泡沫理论

Gibbs-Marangoni 效应：液膜受拉伸变薄 → 局部表活浓度降低 → 表面张力梯度驱动液体回流 → 液膜自动修复变厚，使泡沫有"弹性"。Ross-Miles 法：H₀ 起泡力、H₅ 稳泡力，二者是独立概念。

④ 洗涤去污五步

润湿渗透 → 卷缩脱离 → 乳化分散 → 增溶稳定 → 悬浮冲洗。表活降低水的表面张力让洗液渗透污垢与基底之间，亲油基插入油污使其卷缩脱离，再经乳化增溶防止重新沉积。

复配协同效应 — 正则溶液理论（RST）

1/CMC_mix = α₁/(f₁·CMC₁) + α₂/(f₂·CMC₂)　·　β < 0 协同（吸引）· β = 0 理想 · β > 0 拮抗（排斥）
β 值含义典型体系
< -5强协同阴离子-两性体系（AES+CAB，β≈-10~-20）
-2 ~ -5中等协同阴离子-非离子体系（AES+AEO）
≈ 0理想混合同类型表活（两种非离子混合）
> 0拮抗阴离子-阳离子（正负电荷结合沉淀）
复配协同效应（重点）：阴离子-两性体系（AES+CAB）β≈-10~-20，是最强的协同组合。甜菜碱季铵阳离子中和 AES 头基负电荷 → 静电排斥减弱 → 头基有效面积 a 减小 → CPP 从 <1/3 提升至 1/3~1/2 → 球形胶束变蠕虫状 → 缠绕成网络 → 粘度急剧上升。这就是"CAB 协同 AES 增稠"的分子机制，也是二合一洗发水能同时清洁+调理的理论基础。
